# Copilot instructions

## Cost-conscious workflow
- Prefer the lowest-cost capable model for simple tasks.
- Plan before implementing.
- Use one objective per Agent run.
- Edit only files relevant to the requested task.
- Do not perform unrelated refactors.
- Run targeted tests before the full test suite.
- Keep responses and explanations concise.
- If the task fails, explain the problem before retrying.
- Use stronger models only for difficult debugging, major refactors, or architecture work.
