آموزش راه‌اندازی، ویرایش و شخصی‌سازی ۳ نسخه مختلف از وب‌سایت شخصی شما

معرفی و ساختار فایل‌ها

این مجموعه شامل ۳ قالب متفاوت با طراحی‌های مدرن و اختصاصی برای متخصصین هوش مصنوعی و برنامه‌نویسان است:

  • index.html : قالب اول - طراحی مدرن با استفاده از Grid (بنتو باکس).
  • index2.html : قالب دوم - طراحی توسعه‌دهنده با منوی سایدبار ثابت.
  • index3.html : قالب سوم - طراحی سایبرپانک و ترمینال هکری (بسیار خاص).

ویرایش اطلاعات پایه (مشترک در تمام قالب‌ها)

برای تغییر لینک شبکه‌های اجتماعی، آیکون‌های FontAwesome قرار داده شده‌اند. صفت href="#" را تغییر دهید:

<a href="https://github.com/YourUsername" class="social-icon">
    <i class="fab fa-github"></i>
</a>

ویرایش ساختار قالب اول

در فایل index.html بخش <section id="home"> را پیدا کنید. برای تغییر تصویر پروفایل و نام:

<h1 class="name">من <span class="gradient-text">آریا راد</span> هستم</h1>
<img src="./assets/images/عکس_شما.jpg" alt="نام شما" class="profile-img">

مدیریت بنتو باکس‌ها (Bento Grid)

بخش "درباره من" در قالب اول به صورت شبکه‌ای از باکس‌ها طراحی شده است. کلاس‌های کنترلی:

  • bento-large : باکس بزرگ (۲ ستون و ۲ ردیف).
  • bento-medium : باکس متوسط (۲ ستون و ۱ ردیف).
  • bento-small : باکس کوچک (۱ ستون و ۱ ردیف).
مخصوص قالب اول (index.html)

مدل‌های زنده (ترمینال و شبکه‌های عصبی)

برای ویرایش انیمیشن‌ها و متن‌های زنده قالب اول، باید فایل main.js را باز کرده و آرایه‌های متنی یا متغیرهای مربوط به Canvas را ویرایش کنید.

قالب دوم بر اساس طراحی IDE ساخته شده است. برای ویرایش منوی کناری، <nav class="sidebar"> را پیدا کنید:

<ul class="nav-menu">

        <div class="folder-icon"><i class="far fa-folder-open"></i></div>

تنظیمات پروفایل و لوگوی ترمینال

قالب سوم دارای استایل هکری و سایبرپانک است. لوگوی بالای صفحه به شکل خط فرمان طراحی شده است:

<!-- تغییر لوگوی هدر -->
<a href="#" class="logo">root@aria<span class="cursor-blink">_</span></a>

اطلاعات پنل سایبری (Hero Section)

در بخش اول صفحه، یک پنل اطلاعات هویتی قرار دارد. مقادیر زیر را با اطلاعات خود جایگزین کنید:

<div class="data-row"><span class="label">شناسه:</span> USR-9982</div>
<div class="data-row"><span class="label">نقش:</span> متخصص یادگیری عمیق</div>

ویرایش مهارت‌ها (ساختار JSON)

در قالب سوم، بخش مهارت‌ها و اطلاعات پایه به صورت کدهای واقعی JSON نمایش داده می‌شود. برای ویرایش آن، کلاس json-code را پیدا کرده و مقادیر داخل کوتیشن‌ها ("") را تغییر دهید:

<pre class="json-code fa-text">
{
  <span class="string">"نام"</span>: <span class="string">"آریا راد"</span>,
  <span class="string">"تخصص_اصلی"</span>: [<span class="string">"مدل‌های زبانی"</span>, <span class="string">"MLOps"</span>]
}
</pre>
مخصوص قالب سوم (index3.html)

سوابق کاری (فرمت Git History)

بخش سوابق در قالب سوم شبیه به تاریخچه کامیت‌های گیت (Git Commit Log) طراحی شده است. برای اضافه کردن سابقه جدید، یک بلاک <div class="commit"> کپی کنید:

<div class="commit">
    <div class="commit-hash">commit <span class="hash-color">f9e8d7c</span></div>
    <div class="commit-author">نویسنده: Aria &lt;ایمیل-شرکت@domain.com&gt;</div>
    <div class="commit-date">تاریخ: ۲۰۲۱ - ۲۰۲۳</div>
    <div class="commit-msg">ویژگی: عنوان شغل یا دستاورد شما</div>
    <p class="commit-desc fa-text">توضیحات کامل در مورد وظایف...</p>
</div>
نکته: برای زیبایی بیشتر، به جای f9e8d7c می‌توانید از عبارات تصادفی هش شده (مثل a1b2c3d) استفاده کنید تا حس ترمینال واقعی‌تر شود.

عناوین دارای افکت گلیچ (Glitch Titles)

عناوین بخش‌ها در قالب سوم دارای افکت لرزش و گلیچ هستند. اگر می‌خواهید متنی مثل "معماری_سیستم" را تغییر دهید، حتماً باید صفت data-text را نیز همزمان با متن داخلی تغییر دهید:

مهم: اگر متن داخل تگ و متن data-text یکسان نباشند، افکت گلیچ به درستی کار نخواهد کرد! 
<!-- روش صحیح تغییر عنوان -->
<div class="glitch-title" data-text="درباره_من">درباره_من</div>

فرم تماس ترمینالی

فرم تماس در انتهای صفحه سوم نیز شبیه خط فرمان طراحی شده است (cmd-label). برای تغییر متون راهنمای فرم:

<span class="cmd-label en-text">نام_کاربری:~$</span>
<input type="text" class="cmd-input fa-text" placeholder="نام شما...">
